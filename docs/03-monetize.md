# Monetize

**Goal:** Capture value without fake traction.

## Outputs

- One primary capture method
- A price or clear non-price goal (e.g. email list, design partners)
- An experiment log entry
- Honest metrics (including zeros)

## Capture methods (pick one first)

| Method | Fits when |
| --- | --- |
| Paid digital product | Artifact is reusable without you |
| Service / done-with-you | You sell judgment, not just files |
| Community | People want peers + accountability |
| Sponsorship / affiliate | Audience exists; disclose clearly |
| Leverage only | You’re still proving demand — OK, label it |

## Steps

### 1. Offer in one sentence
*For [audience], [artifact] helps [outcome]. It’s [price / ask].*

### 2. Instrument lightly
Count what matters: pays, replies, completes checklist, stars **with intent**.  
Vanity metrics without a decision are noise.

### 3. Run a time-boxed experiment
Example: 14 days, one channel, one offer.  
Write results even if the result is “nobody cared.”

### 4. Decide
- Double down
- Pivot Find
- Kill

Use labels from [`04-labels.md`](04-labels.md).

## Anti-patterns

- Invented waitlists / revenue
- “Guaranteed income” language
- Monetizing before any Find evidence (unless explicitly a leverage bet)

## Exit criteria

You can show a dated experiment card with real numbers — including zero.
