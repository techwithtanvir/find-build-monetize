# Labels

Use these labels in notes, READMEs, and experiment cards so you don’t launder guesses as facts.

| Label | Meaning |
| --- | --- |
| **FACT** | Observable, checkable, sourced |
| **HYPOTHESIS** | Testable belief; needs an experiment |
| **ASSUMPTION** | Unverified; treat as risky |
| **EXPERIMENT** | Time-boxed test with a success/fail rule |
| **DECISION** | Choice we commit to until revisited |

## Example

- FACT: Solo builders ask “which AI coding agent?” weekly in community X.
- HYPOTHESIS: A one-page evaluation checklist reduces tool-switching.
- EXPERIMENT: Publish checklist; measure saves/forks + 5 qualitative replies in 14 days.
- DECISION: If &lt;3 meaningful replies, revisit Find before building a product.
